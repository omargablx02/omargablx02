## About

I'm an IT Specialist with more than two years administering the network, server
and device estate behind a multi-branch retail operation in New Cairo, where
downtime means empty shelves and lost revenue.

I work across the whole stack rather than one layer of it: LAN and Wi-Fi,
Windows Server infrastructure, CCTV, the ERP and CRM platforms the business runs
on, and the automation that keeps the repetitive parts from eating my week.

## What I Work With

Everything below is current, not historical. Networking and devices are what I
own day to day; the rest is the skill behind it.

| Domain | Detail |
| :--- | :--- |
| **Networking** | LAN and Wi-Fi across 10+ TP-Link switches and 14 UniFi access points, with 5+ branches connecting into HQ. TCP/IP, subnetting, VLANs and ACLs day to day; OSPF, HSRP and static routing built and tested in Packet Tracer lab designs |
| **Devices** | 55+ PCs, 85+ Odoo tablets in daily use, and 30+ network printers |
| **Servers** | 8 Windows Server 2012–2016 RDP session and application servers — each branch connects to two, with the databases hosted on the main HQ server |
| **CCTV** | 80+ Hikvision IP cameras (indoor, outdoor and PTZ) across 2 storage servers with 25-day retention, from camera placement through IP addressing and NVR configuration |
| **Platforms** | Odoo ERP and Salesforce CRM administration across all branches — users, permissions and day-to-day support |
| **Security** | User access control, per-user content restrictions, account provisioning and offboarding, and permission management across the ERP and CRM |
| **Systems** | Windows Server 2012–2016 administration, RDP-based remote administration, user and permission management, VMware Workstation, and Linux (RHEL, Rocky, Ubuntu). Active Directory (AD DS, OUs, GPO) is lab and self-study work, not production |
| **Backup** | ~44 GB daily across the server estate with Windows Server Backup to external storage |
| **Automation** | Python (OOP), PowerShell, Bash and shell automation, and Windows Batch, all version-controlled with Git and GitHub |
